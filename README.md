# STM32 多功能桌面终端与小游戏系统

基于 STM32F103C8、OLED 和多个外设实现的多功能嵌入式终端项目。项目包含时钟、菜单交互、秒表、LED 调光、MPU6050 姿态检测、电池电量检测，以及小恐龙和贪吃蛇游戏。

## 主要功能

- OLED 128×64 图形界面和多级菜单。
- RTC 实时时钟和日期显示。
- 秒表功能。
- PWM 控制 LED 亮度。
- ADC 检测电池电量。
- I2C 读取 MPU6050，实现姿态数据和水平仪显示。
- 小恐龙游戏：跳跃、障碍物移动、碰撞检测和分数计算。
- 贪吃蛇游戏：Key1 左转、Key2 右转、吃食物、身体增长、得分和碰撞检测。
- 游戏选择界面中的历史高分页面。
- 使用 STM32 内部 Flash 保存小恐龙和贪吃蛇的历史最高分，掉电不丢失。

## 硬件与软件

- MCU：STM32F103C8
- 显示：128×64 OLED
- 传感器：MPU6050
- 开发环境：Keil MDK / uVision
- 编程语言：C
- 外设库：STM32F10x Standard Peripheral Library
- 通信与外设：GPIO、TIM、I2C、ADC、PWM、RTC、内部 Flash

## 按键说明

| 按键 | 功能 |
| --- | --- |
| Key1 | 上一项；贪吃蛇左转 |
| Key2 | 下一项；贪吃蛇右转 |
| Key3 | 确认、进入或返回 |

## 贪吃蛇说明

- 蛇头和食物均为 4×4 像素。
- 蛇身使用居中的 2×2 像素显示，与蛇头区分。
- 游戏区域带有明确边框，边框不可穿越。
- 蛇移动周期约为 150 ms。
- 食物只会生成在边框内部。

## 历史高分存储

项目使用 STM32 内部 Flash 最后一页保存高分数据：

- 存储地址：`0x0800FC00`
- 预留空间：1 KB
- 保存内容：小恐龙最高分、贪吃蛇最高分、魔数和校验值
- 只有产生新纪录时才擦写 Flash，减少擦写次数

注意：工程已经将程序 IROM 空间调整为 `0xFC00`，为高分数据预留最后 1 KB。若更换 MCU 或修改 Flash 容量，需要同步调整 `Hardware/ScoreFlash.c` 和 Keil 的 IROM 配置。

## 工程结构

```text
Hardware/   OLED、按键、MPU6050、菜单和游戏代码
Library/    STM32F10x 标准外设库
Start/      启动文件和系统时钟代码
System/     延时、定时器和 RTC
User/       main.c 和中断处理
Project.uvprojx
```

## 编译与下载

1. 使用 Keil MDK 打开 `Project.uvprojx`。
2. 确认芯片型号和启动文件与目标板一致。
3. 执行 Rebuild 编译工程。
4. 连接 ST-Link 或其他下载器后下载程序。
5. 首次运行时历史高分默认为 0，产生新纪录后自动保存。
